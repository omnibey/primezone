==================================================
        KOTHBEL & ETHNICAURA LOCAL SETUP GUIDE
==================================================

এই গাইডটি নতুন কোনো পিসি বা ফ্রেন্ডের ল্যাপটপে প্রজেক্ট সেটআপ করার সম্পূর্ণ গাইড।
নিচের ধাপগুলো সিরিয়ালি ফলো করো:

ধাপ ১: প্রয়োজনীয় সফটওয়্যার ইনস্টল
--------------------------------------------------
১. প্রথমে Node.js (v18 বা v20+ LTS) ইনস্টল করতে হবে।
   লিংক: https://nodejs.org
   (LTS ভার্সন ডাউনলোড করে সাধারণ সফটওয়্যারের মতো Next -> Next দিয়ে ইনস্টল করো)।
২. Git ইনস্টল করা না থাকলে ইনস্টল করে নাও: https://git-scm.com/

ধাপ ২: প্রজেক্ট ক্লোন / ডাউনলোড করা
--------------------------------------------------
১. যেকোনো একটা ফোল্ডারে যাও (যেমন D: ড্রাইভ বা C:\Projects)।
২. সেখানে Terminal বা Command Prompt (cmd) ওপেন করো।
৩. নিচের কমান্ড দিয়ে কোড ইন্টারনেট থেকে নামিয়ে নাও:
   git clone https://github.com/bayazidzaman/kothbel.git
   git clone https://github.com/bayazidzaman/ethnicaura.git

ধাপ ৩: সিক্রেট ভেরিয়েবল সেটআপ (খুবই গুরুত্বপূর্ণ)
--------------------------------------------------
১. প্রজেক্ট ফোল্ডারের ভেতরে 'worker' নামে একটি সাব-ফোল্ডার আছে।
   (যেমন: kothbel/worker এবং ethnicaura/worker)
২. ওই 'worker' ফোল্ডারের ভেতরে '.dev.vars' নামে নতুন একটি ফাইল তৈরি করো।
৩. ওই ফাইলের ভেতরে নিচের দুটো লাইন হুবহু কপি করে পেস্ট করে সেভ করো:

ধাপ ৪: প্যাকেজ ইনস্টল ও ডিপেন্ডেন্সি সেটআপ
--------------------------------------------------
১. টার্মিনালে মূল প্রজেক্ট ফোল্ডারের ভেতরে যাও:
   cd kothbel
২. ডিপেন্ডেন্সিগুলো ইনস্টল করো:
   npm install

ধাপ ৫: ওয়েবসাইট চালু করা (Development Mode)
--------------------------------------------------
১. লোকাল ডেভেলপমেন্ট সার্ভার চালু করতে কমান্ড দাও:
   npm run dev

২. ব্রাউজারে নিচের লিংকে যাও:
   👉 ওয়েবসাইট: http://localhost:3000
   👉 অ্যাডমিন প্যানেল: http://localhost:3000/admin

--------------------------------------------------
💡 টিপস (Cloudflare Worker API লোকালি টেস্ট করতে চাইলে):
--------------------------------------------------
মূল ওয়েবসাইট অটোমেটিক ক্লাউডের লাইভ API-এর সাথে কানেক্টেড থাকে। তবে Worker কোড লোকালি টেস্ট করতে চাইলে:
১. নতুন আরেকটি টার্মিনাল ওপেন করো।
২. worker ফোল্ডারে যাও:
   cd worker
৩. কমান্ড দাও:
   npx wrangler dev
(Worker লোকালি http://localhost:8787 এ চালু হবে)।
